# Security Policy

## Supported releases

Only the latest published release is supported.

Unreleased branches, pull requests, and release candidates are provided for review and testing, not as supported releases. Use the [latest published GitHub release](https://github.com/Muhammad-Zonain/checkout-release-passport/releases/latest) and pin its reviewed full commit SHA in production.

## Report a vulnerability privately

Do not open a public GitHub issue for a suspected vulnerability.

Email:

`hello@transferverity.com`

Use this subject:

`[SECURITY] Checkout Release Passport`

Include, where safe:

- the affected release or commit SHA;
- minimal reproduction steps;
- expected security impact;
- safely redacted logs or screenshots;
- whether the issue is publicly known.

Do not send:

- credentials or access tokens;
- cardholder or payment data;
- cookies or session values;
- customer information;
- private checkout URLs;
- complete private repository content;
- unredacted secrets or logs.

I aim to acknowledge a report within three business days and provide a
triage update within seven business days.

Please allow reasonable time for investigation and remediation before
public disclosure.
